# architecture-mentor

Skill educativa: antes de construir, te enseña a decidir arquitectura, infraestructura y stack (una decisión cada vez, con opciones, "mejor si…" y recomendación); después de construir, te explica qué tiene un proyecto y por qué.

- `SKILL.md`: instrucciones y flujo
- `references/`: cuestionario, catálogo de opciones, plantilla ADR, modo revisión

Estado: v0.1 (borrador probado a mano con un caso real; sin evals automáticos todavía). Funciona con o sin un grafo de graphify.
